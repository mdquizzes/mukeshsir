👨‍🏫 How to Use the Slides

1. Open a Chapter

Click the chapter card. The chapter opens as a dedicated classroom teaching page.

2. Use Fullscreen

Click Fullscreen before teaching. This gives maximum screen space on a projector or classroom display.

3. One Question at a Time

Use Previous and Next. Each question/sub-question gets its own screen so students focus on the current problem.

4. Teacher Whiteboard

Use the pen to write your solution directly on the large blank whiteboard. Use colour, eraser, undo, redo and clear when needed.

5. Textbook Figure

When a question has a figure, the textbook image appears with the question. The teacher can use the figure during explanation.

6. Highlight Different Regions

Choose a colour, select Fill Region, click the vertices of a triangle/region and fill it. Repeat with another colour for another region in the same diagram.

7. Solution

The Solution button is reserved for separate detailed solution files. These can later contain topper-style, step-by-step answers.

8. Classroom Tip

First let students attempt the question. Then write the solution step-by-step on the whiteboard. Open the prepared solution only when you want to reveal/check the final reasoning.

Recommended teaching flow: Read the question → ask students to think → discuss the approach → write the solution on the whiteboard → use the textbook figure and colour highlighting → finally open the Solution tab for checking.

⌨️ Useful Controls

  1. Next / Previous — move between questions.
  2. Fullscreen — maximum classroom display area.
  3. Pen — write on the whiteboard.
  4. Eraser — erase writing.
  5. Colour — change pen colour.
  6. Undo / Redo — correct writing quickly.
  7. Fill Region — colour different triangles/regions in the textbook figure.
  8. Solution — open the separate prepared solution when available.
